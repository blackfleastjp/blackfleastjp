How to push code to git

1. Open your terminal or command prompt.

2. Navigate to the root directory of your project using the 'cd' command.

3. Check the status of your repository by running the command: git status. This will show you the changes that have been made.

4. Add the changes you want to commit by running the command: git add . (This adds all changes. You can also add specific files by replacing '.' with the file names.)

5. Commit the changes with a descriptive message by running the command: git commit -m "Your commit message here".

6. Push the changes to the remote repository by running the command: git push origin main (Replace 'main' with your branch name if it's different.)

7. If prompted, enter your GitHub username and password or personal access token to authenticate the push.

8. Your changes should now be pushed to the remote repository on GitHub.
